# Changelog

All notable changes to this project are documented here.

## [Unreleased]

## [0.1.0] - 2026-11-06

### Added
- Initial system generated from the Foundry VTT boilerplate.
- Actor data models: shared base, character, and NPC.
- Rules config for attributes, actions, mastery levels, efficiency multipliers, and load levels.
- Character sheet with attributes, actions, spiritual energy, Power Understanding, burnout scars, load, experience, and background.
- Derived efficiency multiplier.
- Brazilian Portuguese translation.
- SCSS styling with light and dark themes and a responsive layout.
- .editorconfig for consistent formatting.

### Changed
- Migrated manifest to Foundry v14 format (documentTypes, grid).
- Replaced boilerplate metadata, README, and license header.

### Removed
- template.json and placeholder library.
- Boilerplate example content: D&D data models, sheets, templates, and styles.
